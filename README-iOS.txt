วิธีติดตั้ง My Wallet v3 บน iPhone (iOS)
=======================================
1. แตกไฟล์ ZIP นี้ลงในโฟลเดอร์ หรืออัปโหลดขึ้นโฮสติ้งฟรี (เช่น GitHub Pages, Netlify, Vercel) หรือเปิดผ่านแอปเว็บเซิร์ฟเวอร์บนเครื่อง
2. เปิดลิงก์ด้วยเบราว์เซอร์ Safari บน iPhone
3. แตะปุ่ม "แชร์" (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้นด้านล่าง)
4. เลื่อนลงมาเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
5. กด "เพิ่ม" (Add) — แอปจะปรากฏบนหน้าจอหลักพร้อมใช้งานแบบเต็มจอและทำงานออฟไลน์ได้ทันที
